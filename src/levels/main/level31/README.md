# 数据操作 - 插入数据 - 基础插入

## 教程

恭喜你学完了查询篇!前面 30 关我们一直在用 select 从数据表中查询数据,但大家有没有想过,表里的数据一开始是怎么来的?

这就要请出 SQL 的三大数据操作语句了:

- 插入数据:insert into
- 更新数据:update
- 删除数据:delete

它们和 select 一起,构成了常说的"增删改查"(CRUD),是 SQL 最核心的四大操作。接下来的几关,我们就来一一攻克它们。

本节学习插入数据,使用 insert into 语句可以向表中添加一行新数据,基本语法如下:

```sql
insert into 表名 (列名1, 列名2, ...) values (值1, 值2, ...);
```

列名和值要按顺序一一对应。对于设置了自增的主键(比如本关 student 表的 id 列),不需要指定,数据库会自动生成。

## 示例

当前 student 表共有 10 名学生:

| id | name | age | class_id | score | exam_num |
| ---- | ---- | ---- | ---- | ---- | ---- |
| 1 | 鸡哥 | 25 | 1 | 2.5 | 1 |
| 2 | 鱼皮 | 18 | 1 | 400 | 4 |
| 3 | 热dog | 40 | 2 | 600 | 4 |
| 4 | 摸FISH | null | 2 | 360 | 4 |
| 5 | 李阿巴 | 19 | 3 | 120 | 2 |
| 6 | 老李 | 56 | 3 | 500 | 4 |
| 7 | 李变量 | 24 | 4 | 390 | 3 |
| 8 | 王加瓦 | 23 | 4 | 0 | 4 |
| 9 | 赵派森 | 80 | 4 | 600 | 4 |
| 10 | 孙加加 | 60 | 5 | 100.5 | 1 |

现在插入一名新学生:

```sql
insert into student (name, age, class_id, score, exam_num)
values ('阿珍', 21, 5, 88, 1);
```

执行成功后,阿珍被分配自增 id = 11。再用全表查询看看结果:

```sql
select * from student;
```

可以看到学生表变成了 11 行,最后一行正是新插入的阿珍。
