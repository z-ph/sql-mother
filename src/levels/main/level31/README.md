# 数据操作 - 插入数据 - 基础插入

## 教程

恭喜你学完了查询篇!前面 30 关我们一直在用 select 从数据表中查询数据,但大家有没有想过,表里的数据一开始是怎么来的?

这就要请出 SQL 的三大数据操作语句了:

- 插入数据:insert into
- 更新数据:update
- 删除数据:delete

它们和 select 一起,构成了常说的"增删改查"(CRUD),是 SQL 最核心的四大操作。接下来的几关,我们就来一一攻克它们。

本节学习插入数据,使用 insert into 语句可以向表中添加一行新数据,基本语法如下:

```sql
insert into 表名 (列名1, 列名2, ...) values (值1, 值2, ...);
```

列名和值要按顺序一一对应。对于设置了自增的主键(比如本关 student 表的 id 列),不需要指定,数据库会自动生成。

## 示例

让我们来看一个具体的插入示例。student 表存储学生的信息(学号 id、姓名 name、年龄 age、班级编号 class_id、分数 score、考试次数 exam_num),当前共 10 行,节选如下:

| id | name | age | class_id | score | exam_num |
| ---- | ---- | ---- | ---- | ---- | ---- |
| 1 | 鸡哥 | 25 | 1 | 2.5 | 1 |
| 2 | 鱼皮 | 18 | 1 | 400 | 4 |
| ... | ... | ... | ... | ... | ... |
| 10 | 孙加加 | 60 | 5 | 100.5 | 1 |

现在,3 班来了一名转学生小灵,18 岁,分数 330,考试 1 次。把她的信息插入 student 表:

```sql
insert into student (name, age, class_id, score, exam_num)
values ('小灵', 18, 3, 330, 1);
```

执行成功后,小灵被分配自增 id = 11。再查询验证:

```sql
select * from student;
```

查询结果(节选):

| id | name | age | class_id | score | exam_num |
| ---- | ---- | ---- | ---- | ---- | ---- |
| ... | ... | ... | ... | ... | ... |
| 10 | 孙加加 | 60 | 5 | 100.5 | 1 |
| 11 | 小灵 | 18 | 3 | 330 | 1 |

可以看到学生表最后一行就是新插入的小灵,自增 id 无需手动指定,数据库自动分配。
