# 数据操作 - 增删改综合练习

## 教程

学完了 insert、update、delete,欢迎来到综合练习关!真实场景中,这三类操作往往要组合使用,比如:新同学转入了(增)、有同学考出了新纪录(改)、不符合条件的学生被移出名单(删)。

本关把三种操作串联成一道题,按顺序执行即可。注意每步都会影响后续步骤的数据,执行完别忘了用全表查询检查最终结果。

## 示例

用一个迷你场景演示三步走(数据仅供演示,与本关题目无关):

第一步,插入转学生沙师弟:

```sql
insert into student (name, age, class_id, score, exam_num)
values ('沙师弟', 30, 3, 350, 2);
```

第二步,给老李加油(老李 score 原为 500):

```sql
update student set score = 520 where name = '老李';
```

第三步,移除分数低于 5 分的学生:

```sql
delete from student where score < 5;
```

最后查询 select * from student; 可以看到:沙师弟出现在表尾,老李的分数变了,低分学生消失了——增、改、删的效果一次全有。

## 题目

student 表初始为前 30 关常用的 10 名学生数据。请**按顺序**编写 SQL 完成以下操作:

1. 插入转学生:姓名 大聪明,年龄 30,班级编号 2,分数 555,考试次数 2;
2. 将 鱼皮 的 score 更新为 666;
3. 删除所有 exam_num 小于 2 的学生;
4. 通过 `select * from student` 查询最终的学生表。
