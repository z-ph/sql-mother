# 数据操作 - 插入数据 - 批量插入

## 教程

上一关我们插入了一条数据。如果要一次插入多条数据,难道要执行多次 insert 语句吗?

不必!insert into 语句支持批量插入,只需要用逗号分隔多组值:

```sql
insert into 表名 (列名1, 列名2, ...) values
(值1, 值2, ...),
(值3, 值4, ...),
(值5, 值6, ...);
```

一条语句即可同时插入多行,各行之间用逗号隔开,最后以分号结束。相比逐条插入,批量插入不仅写起来简洁,执行效率也更高。

## 示例

一次插入两名转学生张三和李四:

```sql
insert into student (name, age, class_id, score, exam_num)
values
    ('张三', 20, 2, 300, 1),
    ('李四', 21, 3, 310, 2);
```

两名学生会被依次分配自增 id = 11 和 id = 12。再执行 select * from student; 就能看到学生表多出两行,共 12 行数据。
