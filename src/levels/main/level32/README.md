# 数据操作 - 插入数据 - 批量插入

## 教程

上一关我们插入了一条数据。如果要一次插入多条数据,难道要执行多次 insert 语句吗?

不必!insert into 语句支持批量插入,只需要用逗号分隔多组值:

```sql
insert into 表名 (列名1, 列名2, ...) values
(值1, 值2, ...),
(值3, 值4, ...),
(值5, 值6, ...);
```

一条语句即可同时插入多行,各行之间用逗号隔开,最后以分号结束。相比逐条插入,批量插入不仅写起来简洁,执行效率也更高。

## 示例

教务处批量录入了两个转学生:张三(20 岁,2 班,300 分,考试 1 次)和李四(21 岁,3 班,310 分,考试 2 次)。用一条语句把他们同时插入 student 表:

```sql
insert into student (name, age, class_id, score, exam_num)
values
    ('张三', 20, 2, 300, 1),
    ('李四', 21, 3, 310, 2);
```

执行成功后,两人被依次分配自增 id = 11 和 id = 12。再查询验证:

```sql
select * from student;
```

查询结果(节选):

| id | name | age | class_id | score | exam_num |
| ---- | ---- | ---- | ---- | ---- | ---- |
| 9 | 赵派森 | 80 | 4 | 600 | 4 |
| 10 | 孙加加 | 60 | 5 | 100.5 | 1 |
| 11 | 张三 | 20 | 2 | 300 | 1 |
| 12 | 李四 | 21 | 3 | 310 | 2 |

学生表多出两行,共 12 行。多组值之间用逗号分隔,一条语句想插多少行都行。
